# Features

The feature status catalog is maintained in
`src/harmony_one/data/features.json`.

| Feature | Status | Source |
|---|---|---|
| Local project editing (devices/activities JSON) | Working | Prior own code |
| Bundled IR device library (82 profiles) | Partial; opt-in via "Add from IR library..."; new projects start blank | Flipper-IRDB, CC0 |
| Flipper `.ir` import | Partial | Prior own code |
| Harmony One configuration backup over USB | Read-only | Public protocol docs |
| Remote menu-icon library | Icons tab reads and saves a validated full backup, then exports each distinct 51 x 48 activity/device menu icon as PNGs to the `icons` folder beside `backups`; user-added PNG/GIF files in that folder are offered in the Change icon picker | Own picture-bank decoder |
| Slideshow image library | Slideshow tab seeds a `slideshow` folder beside `backups` with the charging battery and three blurred-light images from the oldest newer-profile backup. It shows six default slots (four images and two empty placeholders) and provides a per-slot image browser for supported loaded cycles, including six-image cycles. Slots beyond the backup's cycle stay empty and disabled and do not play | Owner backup picture-cycle decoder |
| Slideshow timing and default reset | Per-slot whole-second timing for supported slots; all six default fields start at 3 seconds, while loading preserves actual backup timings. Return to default restores the four original bundled images at 3 seconds each and shortens a supported six-image cycle to four, leaving two empty/disabled slots. Candidate-only until guarded write; timer isolation and byte preservation are checked, but timing/cycle-shortening hardware behavior is unverified | Own bounded timer editor + bundled owner artwork |
| Home remote preview | Read-only Home preview shows the activity/device menu pages, names, order, row artwork, icons, and identified style from the last scanned or loaded backup | Own GSPM, screen, and picture decoders |
| Separate device/activity object export | Partial; individual objects selectable, one-click fresh-backup export; archival data only, not upload-ready | Own decoders |
| Backup browser (Browse Contents section of Backups & Transfer) | Decodes names, IR summaries, steps and bindings; one action imports all decoded items into a separate Remote Data project copy; can create offline candidates for individual activity/device menu-icon edits, preserving loaded backgrounds and buttons; edited backups can be saved for later transfer | Own decoders + bounded picture-reference edits |
| Visual configuration memory map | Read-only map of header, raw-numbered sections, and checksum/end-marker bytes; shows sizes, offsets, flash addresses and a short hex preview. Unknown section internals are not presented as decoded data; opens local backup files without USB | Own GSPM section parser |
| Transfer one remote to another (Transfer section of Backups & Transfer) | Experimental; a scrollable three-step flow selects or downloads a complete source `.EZHex`, backs up and checks the destination, then requires explicit full-replacement confirmation and verifies the write. Firmware and cross-remote compatibility are not hardware-validated | USB flash writer + own backups |
| Import/export one editable project object at a time | Partial; activity dependencies are copied and IDs remapped; not upload-ready | Own project format |
| Backup explorer (`tools/inspect_backup.py`) | Dev tool | Own analysis |
| Read devices, IR records, activity names and state steps from a backup | Partial | Public docs + own backups |
| Map device buttons to physical/touch-screen buttons | Planned | R1 |
| Local activity setup (devices, ordered actions, optional control roles and input notes) | Partial; local project only, input notes do not send commands | Manual analysis + own project model |
| Local Remote Data activity icons | Partial; built-in and custom 32 x 32 project previews only; these project icons are not uploaded as remote menu artwork | Local project format |
| Per-row remote menu icons | Experimental; device/activity card actions offer selector-free pickers that change matching menu rows. If an activity name has no menu-label match, the picker lists actual backup activity rows. Browse Contents retains per-occurrence editing. Pick an image from the backup, the user icon library, or import PNG/GIF. Saves a separate .EZHex candidate; general Remote Data project icons are not written to the remote. Candidate validation checks picture-bank boundaries, checksum, unrelated rows, and existing style. Hardware appearance and cross-remote compatibility are not validated | Own screen/picture decoders + owner backups |
| Activities/Devices display styles | Experimental; Newer and Older owner-measured styles are bundled, and artwork from a custom donor backup can be named and saved in a local style library for reuse. Transfers list backgrounds and row-button artwork, replaces recognized menu icons with a consistent generic list icon, and preserves labels, device/activity data, and order. Can write through an acknowledgement-gated exact-baseline workflow with full read-back; style writes are not yet hardware-validated | Owner backups + screen-program analysis |
| Custom display-style maker | Foundation; independent Devices/Activities pages create solid, two-colour gradient, or fitted PNG/GIF backgrounds, rounded/sharp buttons, fill colours, and optional coloured 0-24 pixel borders. Saves self-contained artwork in the existing style library for candidate generation and guarded apply. Text controls remain disabled and existing fonts, text colours, boldness, and sizes stay unchanged; hardware appearance is unverified | Own RGB565 artwork renderer + existing style workflow |
| Set remote clock | Partial; Clock tab can save an offline clock candidate from the currently loaded backup, or stamp the current wall time for the computer's local zone or a selected IANA zone and run an acknowledgement-gated, exact-baseline configuration write; the remote does not retain the zone or DST rules, and clock-specific hardware behavior is unverified | Public Harmony format research + owner backups |
| Remote Assistant prompts | Experimental; dedicated page reads a recognized backup's saved prompt setting and saves a separate on/off candidate. Apply uses Backups & Transfer with an exact-original-baseline gate, fresh backup, explicit confirmations, and read-back verification. Retains screens/menu entry; does not install missing assistant support. Assistant-specific screen behavior is hardware-unverified | Measured Options toggle actions and state records |
| Fixed-size slideshow and same-length activity-name writes | Verified on spare | USB writer; owner-confirmed hardware results |
| General project-to-remote configuration generation | Not implemented | Requires an encoder and relocation verification |
| Add activity using existing remote devices | Experimental; Test TV upload/read-back and corrected device-screen navigation owner-confirmed; startup title reused | Approved attributed MIT composer + independent preservation checks |

See [REMOTE-WRITES.md](REMOTE-WRITES.md) for the tested write sequence, evidence,
and current safety boundaries.
